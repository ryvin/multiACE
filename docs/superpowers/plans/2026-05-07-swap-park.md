# Swap-park — implementation plan (v2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `LENGTH=` parameter to the existing `ACE_UNLOAD_HEAD` firmware command so a partial retract parks filament in the ACE-side bowden just past the splitter, enabling faster cross-ACE swaps by skipping the full retract/reload cycle.

**Architecture:** `cmd_ACE_UNLOAD_HEAD` reads an optional `LENGTH=` integer. When present, it runs `FEED_AUTO STAGE=prepare` (heat + tip push) then calls `self._retract(slot, length, self.retract_speed)` directly — bypassing `FEED_AUTO STAGE=doing` whose retract is hardcoded to `self.retract_length`. After partial retract completes, `head_source[N]['parked'] = True` is set and the source ACE/slot are preserved. Full unload (no LENGTH) is unchanged. A one-line JS change replaces the old `ACE_PARK_HEAD` call in `_executeSmartSwapLeg1`. Four convenience macros (`ACEC__Park_T0..T3`) wrap the new parameter for operator use. No new audit shape; existing `UNLOAD_HEAD` event gains optional `length` and `parked` fields.

**Tech Stack:** Python (Klipper extras — `ace.py`), Klipper config (`ace.cfg`), vanilla JS (`app.js`), pytest (web test suite).

**Spec:** `docs/superpowers/specs/2026-05-07-swap-park-design.md`

**Path resolution (pre-investigated):** Path (b). `FEED_AUTO`'s `cmd_FEED_AUTO` does NOT accept a `LENGTH=` parameter. The unload `STAGE=doing` block calls `self.ace.retract_fil(ch)` which calls `self._retract(index, self.retract_length, self.retract_speed)` — always the configured `retract_length`, no override. The implementation bypasses `STAGE=doing` entirely when `LENGTH` is provided, using `self._retract(slot, length, self.retract_speed)` directly after `STAGE=prepare` completes.
