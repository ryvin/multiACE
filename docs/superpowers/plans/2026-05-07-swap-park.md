# Swap-park — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `ACE_PARK_HEAD HEAD=N` firmware command that retracts a head's filament to a calibrated park position in the ACE-side bowden, plus web-side auto-park-on-cross-ACE-swap, so cross-ACE filament swaps avoid the full unload/full reload waste.

**Architecture:** Firmware adds one new gcode command + one config key + one head_source marker. Web adds one helper that detects cross-ACE swap intent and chains park-then-load. Backwards compatible — existing `ACEC__Unload_T<n>` macros and `ACE_LOAD_HEAD` flows untouched.

**Tech Stack:** Python (Klipper extras), Klipper config (ace.cfg), vanilla JS (multiace web).

**Spec:** `docs/superpowers/specs/2026-05-07-swap-park-design.md`

**Critical-review status (per spec §8)**: not yet validated against the actual `_feed_loading` LOAD=0 mechanism. Task 1 below begins by inspecting that path before locking the implementation.

- [ ] **Step 3: Implement the method**

Insert near `cmd_ACE_UNLOAD_HEAD` (around line 1786 of current ace.py). The implementation depends on Task 0's mechanism choice. Below is the pattern assuming `FEED_AUTO LOAD=0 LENGTH=` works:

```python
cmd_ACE_PARK_HEAD_help = (
    "[multiACE] Park a head's filament in the ACE-side bowden just past "
    "the splitter (for swap-back-friendly cross-ACE swaps). Pre-flight: "
    "head_source[N] must be set, e<head>_filament must read True. "
    "Usage: ACE_PARK_HEAD HEAD=N"
)

def cmd_ACE_PARK_HEAD(self, gcmd):
    head = gcmd.get_int('HEAD')
    if head < 0 or head > 3:
        raise gcmd.error('[multiACE] HEAD must be 0-3')

    # Pre-flight: print state must be safe.
    print_stats = self.printer.lookup_object('print_stats', None)
    state = print_stats.get_status(self.reactor.monotonic())['state'] if print_stats else 'unknown'
    if state in ('printing', 'paused'):
        raise gcmd.error('[multiACE] Cannot park during print (state=%s).' % state)

    # Pre-flight: head must be loaded.
    source = self._head_source.get(head)
    if not source:
        raise gcmd.error(
            '[multiACE] Head %d is not loaded; nothing to park.' % head)

    # Pre-flight: head sensor must read True (must have filament to park).
    sensor = self.printer.lookup_object(
        'filament_motion_sensor e%d_filament' % head, None)
    if not (sensor and sensor.get_status(0)['filament_detected']):
        raise gcmd.error(
            '[multiACE] Refusing: e%d_filament reads False — head is empty per sensor. '
            'Bookkeeping is wrong; use ACE_CLEAR_HEADS or ACE_MARK_HEAD_LOADED to fix first.'
            % head)

    ace_index = source['ace_index']
    slot = source['slot']

    # If source ACE isn't active, switch first (park needs to drive that ACE's wheel).
    if ace_index != self._active_device_index:
        if not self._switch_ace_for_head_target(ace_index):
            self._audit_state('PARK_HEAD_FAILED', {
                'head': head, 'ace': ace_index, 'slot': slot,
                'reason': 'switch_failed',
            })
            raise gcmd.error(
                '[multiACE] Failed to switch to ACE %d for park.' % ace_index)

    module, channel = self.EXTRUDER_MAP[head]
    park_length = self.park_retract_length_mm

    self.log_always(
        '[multiACE] Parking head %d (ACE %d slot %d) — retracting %d mm'
        % (head, ace_index, slot, park_length))

    # Issue partial retract via FEED_AUTO LOAD=0 LENGTH= (or chosen mechanism per Task 0).
    try:
        self.gcode.run_script_from_command(
            "FEED_AUTO MODULE=%s CHANNEL=%d EXTRUDER=%d LOAD=0 LENGTH=%d"
            % (module, channel, head, park_length))
    except Exception as e:
        self._audit_state('PARK_HEAD_FAILED', {
            'head': head, 'ace': ace_index, 'slot': slot,
            'reason': 'feed_auto_error', 'error': str(e),
        })
        raise

    # Verify post-condition: e<head>_filament must read False (filament cleared head).
    sensor_post = (sensor and sensor.get_status(0)['filament_detected'])
    if sensor_post:
        self._audit_state('PARK_HEAD_FAILED', {
            'head': head, 'ace': ace_index, 'slot': slot,
            'reason': 'sensor_still_detecting', 'retract_length': park_length,
        })
        raise gcmd.error(
            '[multiACE] Park retract completed but e%d_filament still reads True. '
            'Filament not cleared from head. park_retract_length_mm may be too short '
            '(currently %d). Try a longer length or fall back to ACEC__Unload_T%d.'
            % (head, park_length, head))

    # Mark head_source as parked. Keep ace_index and slot for swap-back routing.
    self._head_source[head] = dict(source)
    self._head_source[head]['parked'] = True
    self._save_head_source()

    self._audit_state('PARK_HEAD', {
        'head': head, 'ace': ace_index, 'slot': slot,
        'retract_length': park_length,
        'e_filament_post': False,
    })
    self.log_always(
        '[multiACE] Head %d parked (ACE %d slot %d, retracted %d mm).'
        % (head, ace_index, slot, park_length))
```

If Task 0 chose the hybrid mechanism, replace the `FEED_AUTO ... LOAD=0 LENGTH=` line with the equivalent two-step:

```javascript
async function pickHeadFor(targetAce, targetSlot, targetHead) {
  // If the target head is currently sourced from a DIFFERENT ACE, park its
  // current filament first (saves ~1 min vs full unload + full reload).
  // Same-ACE swaps skip the park — the existing unload-reload is cheaper
  // for same-ACE because there's no splitter friction to avoid.
  const currentSrc = state.head_source && state.head_source[targetHead];
  if (currentSrc && typeof currentSrc.ace_index === 'number'
      && currentSrc.ace_index !== targetAce
      && !currentSrc.parked) {
    await sendCommand(`ACE_PARK_HEAD HEAD=${targetHead}`);
  }
  await sendScript(
    `ACE_LOAD_HEAD HEAD=${targetHead} ACE=${targetAce} SLOT=${targetSlot}`);
}
```

`sendCommand` and `sendScript` already exist (sendCommand uses the existing macro path which routes to ACE_PARK_HEAD just fine; sendScript is for the ACE_LOAD_HEAD raw-script path).

```markdown
### Cross-ACE swap with park

For swaps between ACEs (e.g., T1 sourced from ACE A → ACE B), use
`ACE_PARK_HEAD HEAD=N` before `ACE_LOAD_HEAD HEAD=N ACE=<new> SLOT=<new>`
instead of `ACEC__Unload_T<n>` + `ACE_LOAD_HEAD`. Park retracts only to
a calibrated bowden park position (~600 mm by default), saving ~1 minute
per swap and leaving the parked filament close to the head for fast
swap-back.

Calibrating `park_retract_length_mm` (in `[ace]` of `ace.cfg`):
1. Run `ACE_PARK_HEAD HEAD=0` from a known-loaded state.
2. Visually inspect: filament tip should be in the ACE-side bowden
   somewhere between the slot gate and the splitter Y-junction.
3. If too far past the splitter (blocks the other ACE's feed): increase
   `park_retract_length_mm` by 50 mm and retry.
4. If filament tip is back at the slot gate (no benefit over full unload):
   decrease by 50 mm.

Convenience macros: `ACEC__Park_T0` through `ACEC__Park_T3` (group H).

multiace web auto-uses park-then-load when the slot row's Load click
targets a different ACE than the head's current source. No operator
gesture needed; just click "→ T<n>" on a slot in the other ACE.
```
